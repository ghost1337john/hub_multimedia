# hub_multimedia
Un hub complet où Plex gère la bibliothèque, Radarr/Sonarr récupèrent films et séries, Prowlarr orchestre les indexers, qBittorrent télécharge via Glutun VPN, Bazarr gère les sous‑titres, Tautulli analyse l’usage et FlareSolverr contourne les protections pour un flux 100% autonome.
